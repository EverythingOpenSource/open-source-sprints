# Everything Open Source Sprints
The Everything Open Source Sprint is an open source sprint designed to welcome contributors of all backgrounds and skill levels. Participants can contribute through code, documentation, research, design, storytelling, and community support, because open source is more than just code.

## Who is this Sprint for?
- New and experienced open source contributors looking to make meaningful contributions
- Maintainers and project teams seeking contributors for open issues and ongoing work
- Communities interested in creating clear contribution pathways and welcoming first-time contributors
